# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| 2.0.x | Yes |
| Earlier | No |

## Reporting a vulnerability

Use the repository's **Security** tab to open a private advisory:

https://github.com/M0-AR/XRay/security/advisories/new

Do not publish exploit details in a public issue. Include the affected edition, browser, steps to reproduce and impact.

## Scope

XRay is a front-end template with no backend, database, authentication service or patient data. Reports about third-party libraries should go to their maintainers unless XRay's configuration makes the issue exploitable.

Read [docs/SECURITY-AND-ACCESSIBILITY.md](docs/SECURITY-AND-ACCESSIBILITY.md) for the security model and production checklist.
