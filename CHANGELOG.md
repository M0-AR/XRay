# Changelog

All notable changes to this repository are recorded here. The project follows semantic versioning for its published editions.

## [2.0.0] - 2026-11-15

### Added

- Interactive preview (`preview.html`) with a 3D hero, live dashboard tabs, feature finder, configurator, ROI calculator, beginner path, healthcare quiz, command palette and a 3D learning game.
- Brand assets: banner, logo and social preview artwork.
- Repository documentation: getting started, customisation, deployment, FAQ, and security and accessibility notes.
- Issue templates, pull request template, citation metadata and a proprietary licence notice.
- Verification workflow template for required files and HTML parsing.
- Docker image workflow template and nginx configuration for the static preview and HTML demo.

### Changed

- Rebuilt the README as a complete, beginner-friendly guide to the suite.
- Expanded the screenshot library to all five dashboards, with WebP versions and a tour GIF.
- Clarified the page count as 72 top-level HTML pages plus three email screens in `html/app/`.
- Added the missing `chart.js` and `react-chartjs-2` dependencies to the React edition.

### Fixed

- Removed inaccurate claims about apps that are not included.
- Clarified that the editions are interface templates, not certified clinical or compliance products.

## Earlier

- Initial public repository with HTML, React and Vue editions.
