# Contributing

XRay is a proprietary project. The repository is public for evaluation, and issues are welcome. Because the code is not open source, please open an issue before sending a pull request; code contributions may require a written agreement.

## Before you open an issue

- Search existing issues.
- Check the [FAQ](docs/FAQ.md).
- Reproduce the problem on the latest version.
- Do not include patient data, secrets or private URLs.

## Bug reports

Use the bug report template. Include:

- The edition: HTML, React or Vue.
- The page or route.
- Browser and operating system.
- Steps to reproduce.
- Expected and actual behaviour.
- Console errors or screenshots when useful.

## Feature requests

Use the feature request template. Explain the healthcare workflow or product problem, not only the UI change. Requests are prioritised by real use, not by volume.

## Pull requests

Open an issue first. If a change is agreed:

1. Keep the change focused on one problem.
2. Match the existing code style and structure.
3. Do not commit generated build output, `node_modules` or secrets.
4. Update the relevant documentation.
5. Confirm that affected pages work at desktop and phone widths.
6. List the pages and editions you tested in the pull request.

## Licensing requests

Open an issue and mark it as a licensing request, or contact the maintainer through https://github.com/M0-AR.

## Code of conduct

Be specific, be respectful and assume good faith. Harassment, discrimination and disclosure of private information are not acceptable.
